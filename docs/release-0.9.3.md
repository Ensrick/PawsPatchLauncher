# Paw’s Launcher 0.9.3

- Add, enable, disable and reorder custom RWD mods from the game settings gear.
- Custom mod lists are saved separately for Vanilla, Immortals and Arcane Wars.
- Fixed repeated errors after cancelling the RWD file picker.
- Support for match recovery in the Vanilla and Immortals beta.

## Русский

- Добавление, включение, отключение и порядок загрузки пользовательских RWD-модов через шестерёнку настроек игры.
- Отдельные списки модов для Vanilla, Immortals и Arcane Wars.
- Исправлены повторяющиеся ошибки после отмены выбора RWD-файла.
- Поддержка восстановления матча в бете Vanilla и Immortals.
