# Paw’s Launcher 0.9.7

- Smaller diagnostic archives: retain the three latest log sets and regular dumps, and only the latest full memory capture.
- AI action logs are excluded. Large text logs retain their beginning and end, including the latest error messages.

## Русский

- Архив диагностики стал компактнее: сохраняются три последних комплекта журналов и обычных дампов, а полный снимок памяти — только последний.
- Логи действий ботов исключены из архива. У больших текстовых журналов сохраняются начало и конец, включая последние сообщения об ошибке.
