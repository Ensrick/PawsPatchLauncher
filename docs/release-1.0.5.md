# Paw’s Launcher 1.0.5

- В общем чате теперь указаны дата и время сообщения.
- Убрана всплывающая подсказка над полем ввода в общем и личном чате.
- Предложение создать архив после вылета игры перенесено в настройки.
- Добавлен переключатель «Игнорировать нулевой боевой дух» для новой беты Arcane Wars. Он требует включённого Paw’s Patch, не зависит от других опций и по умолчанию выключен.
