# Paw’s Patch 0.4.1-beta.10 — Vanilla / Immortals

Fixed widescreen HUD layout: the selected company banner and formation buttons sit on the right, while multiple company cards keep compact spacing on the left. Removed the extra vertical stripe and distorted upper HUD border. Corrected the timer, tooltips, economy preview, recruitment presets and connection dialog positions. The recruitment editor is centered.

Исправлено размещение элементов интерфейса на широком экране: знамя выбранной роты и кнопки строя находятся справа, карточки нескольких рот сохраняют компактные интервалы слева. Убраны лишняя полоса и искажение верхней рамки нижней панели. Исправлены положение таймера, подсказок, предпросмотра экономики, сохранённых наборов найма и окна соединения. Окно найма размещается по центру.

Beta UI update. Existing crash, recovery and lobby-startup fixes are retained. No gameplay or network simulation changes.
