# Paw’s Launcher 1.0.3

Custom RWD mods now show load-order numbers and matching files between enabled mods, with resource paths in tooltips. Replace an archive while preserving its position and enabled state, even at the 32-mod limit. Undo restores the saved mod list; applying changes still uses the existing installation transaction.

Available in Game settings → Custom mods, in all six launcher languages. File matches are advisory: they do not imply multiplayer compatibility. Base-game selection and the Arcane Wars ModDB installation flow are unchanged.

Thanks to Ensrick for [PR #17](https://github.com/VasiliyPaw/PawsPatchLauncher/pull/17). This release adopts the custom-mod improvements; the separate manager-page redesign is not included.

Game packages are unchanged.
