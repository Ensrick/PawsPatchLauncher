# Paw’s Launcher 1.0.1

Fixed a Vanilla startup crash on Kohan II 1.3.68 after playing with extra kingdoms. The launcher repairs incompatible lobby settings using defaults for the detected game version and keeps a backup. General preferences, keybindings and saved games are unchanged. Thanks to Ensrick for the fix.

## Русский

Исправлен вылет при запуске Vanilla на Kohan II 1.3.68 после игры с расширенным числом королевств. Лаунчер восстанавливает несовместимые настройки лобби с учётом версии игры и сохраняет резервную копию. Общие настройки, управление и сохранения не изменяются. Спасибо Ensrick за исправление.

Based on [Ensrick’s PR #19](https://github.com/VasiliyPaw/PawsPatchLauncher/pull/19).
