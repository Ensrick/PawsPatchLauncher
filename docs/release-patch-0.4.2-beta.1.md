# Paw’s Patch 0.4.2-beta.1

- The in-game interface preserves its proportions on widescreen displays.
- Restored the original minimap frames. This improvement is built into Paw’s Patch and needs no separate switch.

Thanks to [Ensrick](https://github.com/Ensrick) for identifying the game’s native widescreen interface option.

## Русский

- Интерфейс игры сохраняет пропорции на широком экране.
- Возвращены оригинальные рамки миникарты. Исправление встроено в Paw’s Patch и не требует отдельного включения.
