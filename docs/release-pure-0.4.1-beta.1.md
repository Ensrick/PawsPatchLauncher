# Paw’s Patch 0.4.1-beta.1 — Vanilla / Immortals

- After a client disconnects, the host automatically saves the match and opens the lobby with that save selected. The player can reconnect, download the save and continue with everyone.
- If the original host disconnects, the new host saves the match and leaves it paused. Resume it by loading the save through a lobby.

Recovery uses the lobby and a saved game. Joining directly into a running simulation is not available yet.

## Русский

- После отключения игрока хост автоматически сохраняет матч и открывает лобби с выбранным сохранением. Игрок может вернуться, получить сейв и продолжить вместе со всеми.
- При потере первоначального хоста новый хост сохраняет матч и оставляет паузу. Продолжить можно, загрузив сохранение через лобби.

Восстановление работает через лобби и сохранение. Вход прямо в работающую симуляцию пока недоступен.
