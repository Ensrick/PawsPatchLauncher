# Paw’s Launcher 1.0.0

- Arcane Wars is available to everyone, including guests.
- The base mod comes from ModDB so the author can see interest through its download count. Darquan’s 0.82.1.8 fix v2 patch is applied separately and automatically.
- If ModDB requires a browser check, the launcher helps you open the site and select the downloaded RAR. Archives and game files are verified before installation.
- A download dialog matching the launcher design. The test-only retry button has been removed.
- Mod contents are unchanged; network compatibility with the previous package is preserved.

## Русский

- Arcane Wars доступен всем пользователям, включая гостей.
- Базовый мод загружается с ModDB, чтобы автор видел интерес к нему по счётчику скачиваний. Патч Даркана 0.82.1.8 fix v2 устанавливается отдельно и автоматически.
- Если ModDB требует проверку в браузере, лаунчер поможет открыть сайт и выбрать скачанный RAR. Архивы и игровые файлы проверяются перед установкой.
- Новое окно загрузки в стиле лаунчера. Тестовая кнопка повторной загрузки удалена.
- Содержимое мода не изменено; сохранена сетевая совместимость с прежним пакетом.
