# Paw’s Launcher 1.0.4

Downloads, file verification, extraction, installation and rollback now run in the background to keep the interface responsive. Progress updates are coalesced to avoid flooding the UI queue. ModDB archive selection and cancellation remain supported.

The current launcher layout is retained. Game packages are unchanged.

---

Загрузка, проверка файлов, распаковка, установка и откат теперь выполняются в фоне, чтобы интерфейс оставался отзывчивым. Обновления прогресса объединяются и не перегружают очередь интерфейса. Выбор архива ModDB и отмена сохраняют корректную работу.

Текущий интерфейс сохранён. Игровые пакеты не изменены.
