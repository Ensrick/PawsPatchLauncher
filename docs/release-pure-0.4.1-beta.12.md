# Paw’s Patch 0.4.1-beta.12 — Vanilla / Immortals

Исправлены пропорции портретов героев, значков найма и квадратных кнопок широкоформатного интерфейса. Кнопка Paw’s Patch уменьшена. Снято ограничение выделения шести рот: карточки используют доступную ширину панели и прокручиваются колёсиком; флажки назначения видны у всех выбранных рот. Строй расширен для групп больше шести рот, исправлено смещение крайних мест. Исправлено ожидание рот при групповом движении и атаке общей цели. Приказ отступления больше не заменяется защитой другой роты.

# Paw’s Patch 0.4.1-beta.12 — Vanilla / Immortals

Corrected the aspect ratio of hero portraits, recruitment icons and square widescreen HUD buttons. Reduced the Paw’s Patch button. Removed the six-company selection limit: cards use the available panel width and support mouse-wheel scrolling; destination flags are shown for all selected companies. Extended formations beyond six companies and corrected displaced outer slots. Fixed group movement waits and shared-target attacks. Explicit Run orders no longer switch to defending another company.
